# 03 · 视觉设计规范

> 废土暗黑风（Wasteland Dark）。设计口号：**像一台在末日里还活着的军用终端**。
> v0.1 纯深色单主题（氛围即产品）；v0.2 可扩展"军用浅色"主题。

---

## 1. 全局设计原则

1. **终端感 > App 感**：等宽数字、方角为主、边框描边、状态文字（`[READY]` / `LOW`），像 PDA 不像消费级 App
2. **低饱和 + 单点高亮**：全站灰绿底色，只有警示黄和辐射绿两个"活色"，其余全部压暗
3. **做旧质感靠叠加不靠贴图**：噪点（SVG feTurbulence 内嵌）+ 扫描线（repeating-linear-gradient）两层 overlay 覆盖全站，成本极低氛围拉满
4. **动效克制**：只在勾选、转场、加载三个点做动画，其余全部瞬间完成——末日设备没电搞特效
5. **对比度达标**：正文对比度 ≥ 4.5:1；警示色用于强调不用于正文

## 2. 设计 Token

### 2.1 色彩

| Token | 值 | 用途 |
|-------|-----|------|
| `--bg` | `#0D0F0C` | 全局背景（近黑军绿） |
| `--bg-panel` | `#151814` | 面板/卡片底 |
| `--bg-raised` | `#1C201A` | 悬浮层/展开区 |
| `--border` | `#2E352A` | 描边（1px 为主） |
| `--border-strong` | `#3F4938` | 强调描边/输入框 |
| `--text` | `#C9CDBE` | 正文（灰绿白） |
| `--text-dim` | `#7C8471` | 次要文字/说明 |
| `--warning` | `#D9C33A` | 警示黄：P2 标记、进度、焦点态（做旧黄，非刺眼金） |
| `--alert` | `#C0533A` | 锈红：P1 标记、红线警示 |
| `--rad` | `#8FBE4F` | 辐射绿：勾选完成、准备度、在线状态（全站唯一"希望色"） |
| `--rad-dim` | `#4A5C33` | 辐射绿暗部：已入库卡片底 |
| `--gray-p3` | `#5A614F` | P3 灰标记 |

### 2.2 字体

| 用途 | 字体栈 | 说明 |
|------|--------|------|
| 标题/品牌 | `"Orbitron", "Noto Sans SC", sans-serif`（离线回退系统黑体） | 英文未来感；中文用黑体 + `letter-spacing: 0.15em` 拉出军用 stencil 感 |
| 正文 | `-apple-system, "PingFang SC", "Noto Sans SC", sans-serif` | 系统字体，保证可读性 |
| 数据/编号/状态 | `"JetBrains Mono", ui-monospace, "SF Mono", monospace` | 物资编号、准备度数字、终端文字，等宽是废土的灵魂 |
| 字号阶梯 | 12 / 13 / 15 / 17 / 22 / 28px | 正文 15px 为主，手机端不小于 13px |

### 2.3 形状与质感

| Token | 值 | 说明 |
|-------|-----|------|
| 圆角 | 卡片 `4px`、按钮 `2px`、徽章 `0` | 锐利为主，拒绝 16px 大圆角的"软"感 |
| 描边 | `1px solid var(--border)` | 面板默认描边；重点面板 `--border-strong` |
| 噪点纹理 | SVG feTurbulence，透明度 `0.04`，`position: fixed` 全站 overlay | 单一实例全局复用 |
| 扫描线 | `repeating-linear-gradient(0deg, transparent 0 2px, rgba(0,0,0,.12) 2px 4px)` | 全站 overlay，透明度可调 |
| 阴影 | 基本不用；悬浮层用 `0 8px 24px rgba(0,0,0,.6)` | 末日里没有柔光 |

## 3. 组件规范

### 3.1 物资卡（核心组件，出现频率最高）

```
┌──────────────────────────────┐
│ [□]  fw-01 瓶装饮用水   [P1]  │  ← 做旧方框勾选框 / 等宽编号 / 优先级章
│      人均 3L/天 × 3 天         │  ← 数量参考（text-dim, 13px）
│      生命底线，断水第一资源      │  ← 一句话说明
└──────────────────────────────┘
```

- 未拥有：`--bg-panel` 底 + `--border` 描边
- 已拥有：勾选框盖章"√"（辐射绿），卡片底变 `--rad-dim`，文字降为 `--text-dim`，右上角追加 `[已入库]` 等宽小字
- 优先级章：小号描边章（P1 锈红 / P2 警示黄 / P3 灰），文字 + 色块描边，不做实底大色块
- 展开（点击）：显示"为什么需要它"+ 关联技能 + 场景标签，底色 `--bg-raised`

### 3.2 准备度模块

- 首页顶部：等宽大数字（28px）+ 段位称号（如 `有备而来`）+ 36px 迷你雷达
- "我的"Tab：SVG 六维雷达图（五大分类拥有率 + 技能练习率），辐射绿描线 + 8% 透明填充，网格线用 `--border`
- 段位颜色：脆皮 `--text-dim` → 路人 `--text` → 有备而来 `--warning` → 老练幸存者 `--rad` → 废土传说 `--rad` + Glitch 微闪

### 3.3 场景卡

- 横向大卡：左侧色带（city 警示黄 / wild 辐射绿 / nuclear 锈红）+ 场景名 + 一行风险概述 + 场景准备度小进度条
- 详情页顶部：风险等级章 `[RISK: MEDIUM]` 等宽字 + 场景专属提示卡（描边锈红）

### 3.4 技能树（v0.2）

- 纵向 5 列分支 × 3 行节点，节点 = 菱形（rotate 45° 方块）
- 状态：未解锁（虚线描边 `--border`）→ 可解锁（警示黄描边 + 呼吸动画一次）→ 已解锁（辐射绿实底）
- 连线：1px 直线，已激活路径辐射绿，其余 `--border`

### 3.5 TabBar（底部导航）

- 4 Tab：清单 / 场景 / 技能 / 我的；图标线性风格（1.5px 描边）+ 等宽小字标签
- 激活态：图标 + 文字变辐射绿，顶部 2px 辐射绿短线
- 背景 `--bg-panel` + 顶部 1px `--border`，不做毛玻璃

### 3.6 终端文字块（点缀组件）

- 加载屏/空状态/提示用等宽字 + 逐字打字机效果：`> 正在加载物资数据库… [OK]`
- 空状态示例：`> 该区域辐射值过高，暂无数据。`

## 4. 动效规范

### 4.1 雷达扫描加载屏（启动 1.2s，可点击跳过）

- 全屏 `--bg`，中心圆形雷达：`conic-gradient(from 0deg, transparent 0 340deg, rgba(143,190,79,.35) 360deg)` 旋转扫描
- 扫描圈上方逐行打字机输出：`> 启动生存终端…` `> 加载物资数据库 [OK]` `> 校验准备度… [OK]`
- 完成后雷达闪一下辐射绿 → 淡出进入首页

### 4.2 Glitch 转场（页面切换，≤ 300ms）

- 两层伪元素实现 RGB 色散：主体 `clip-path` 随机两帧错位（8%/12% 高度切片），红/绿偏移各 2px
- 仅用于 Tab 切换与技能解锁；列表滚动、勾选不用 Glitch（避免疲劳）

### 4.3 印章勾选（≤ 250ms）

- "√"以 `scale(1.4) rotate(-8deg)` 出现 → `scale(1) rotate(-3deg)` 落定，`steps(2)` 跳帧制造机械感
- 同时卡片底色 150ms 过渡至 `--rad-dim`，完成度进度条数字 +1 滚动

### 4.4 克制条款

- 全站循环动画仅 2 处：加载屏雷达（一次性）、可解锁技能节点呼吸（单次）
- `@media (prefers-reduced-motion: reduce)`：关闭全部动画，直接呈现终态

---

## 5. 布局与响应式

- 手机优先：设计基准 375px；内容区最大宽 `480px` 居中（桌面端保持手机比例，两侧 `--bg` 留白 + 细描边模拟终端外框）
- 栅格：清单列表单列；场景卡单列横卡；技能树横向滚动
- 安全区：TabBar 适配 `env(safe-area-inset-bottom)`
- 触控目标 ≥ 44px；物资卡整卡可点，勾选框与卡点击分离（框勾选，卡展开）
