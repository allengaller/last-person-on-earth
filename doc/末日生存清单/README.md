## 🎯 产品一句话

**把「末日生存物资准备」变成一场可收集、可升级的生存游戏：用废土风 UI 包装修物清单数据库，用准备度评分与技能树让"囤货"上瘾。**

## 🌈 核心设计原则

1. **硬核打底，趣味包装**：物资数据专业严谨（对标官方应急清单），外壳废土酷炫
2. **数据模型驱动**：先定实体（物资/场景/技能节点/用户状态），界面从数据推导
3. **氛围感优先**：低饱和配色、做旧纹理、雷达扫描骨架屏、故障风转场——末日题材极度依赖沉浸感
4. **中度游戏化**：准备度评分 + 可解锁技能树 + 成就徽章，游戏化为辅不喧宾夺主
5. **合规即底线**：对标应急管理部《家庭应急物资储备建议清单》方向，医疗条目加"遵医嘱"提示，不引导极端囤积

## 🥊 竞品差异化

| 竞品类型 | 代表 | 痛点 | 我们的机会 |
|---------|------|------|-----------|
| 传统生存 APP | Survival Manual、末日生存手册 | 界面陈旧、交互死板、静态阅读、无个性化 | 废土风 UI + 动态清单 + 游戏化，体验降维打击 |
| Vibe Coding 工具 | Bolt.new / Lovable / 小红书 Vibe Coding | 多做效率软件或小游戏 | 用 Vibe Coding 做垂直垂类硬核工具的示范 |
