# 01 · 产品设计

## 1. 产品定位

**一句话**：把「末日生存物资准备」变成一场可收集、可升级的生存游戏——废土风 UI 的动态物资清单 + 场景化推荐 + 准备度评分 + 技能树。

**产品类型**：响应式 Web App，手机优先设计，底部 TabBar 导航；无后端、无登录，数据全存本地。

**情绪基调**：硬核、酷、克制的黑色幽默。像打开一台末世求生终端（PDA），而不是一款记账工具。骨子里实用，气质上玩梗。

---

## 2. 目标用户

| 维度 | 描述 |
|------|------|
| 核心用户 | 20-35 岁，对末日/废土文化有好感（游戏玩家、美剧观众），同时有真实应急准备意识 |
| 次级用户 | 家有孩童、注重家庭应急储备的实用派（被"酷"外壳吸引后留下来） |
| 使用场景 | 囤货时对照清单采购；灾害新闻后的应急自查；朋友间分享"你的生存准备度是多少" |
| 用户动机 | ① 把模糊的"该囤点什么"变成可执行清单；② 游戏化反馈让准备过程有成就感；③ 分享评分与技能树炫耀 |

---

## 3. 信息架构（4 Tab）

```
Tab1 清单 checklist（首页）
├── 顶部：生存准备度总评（数字 + 小雷达）
├── 分类 tab（食物饮水 / 医疗急救 / 防护工具 / 能源通讯 / 文件身份）
│   └── 物资卡列表（勾选框 + 名称 + 优先级 P1/P2/P3 + 数量参考 + 一句话说明）
└── 分类完成度进度条（做旧样式）

Tab2 场景 scenarios
├── 场景卡列表（城市避难 / 野外求生 / 核污染区）
│   └── 场景详情：风险概述 → 场景准备度 → 推荐物资组合（按优先级分组）→ 场景专属提示
└── v0.3 扩展位：台风暴雨 / 地震 / 疫情居家

Tab3 技能 skills
├── 技能树视图（5 分支 × 3 级，节点+连线）
│   └── 节点详情：描述 + 解锁条件（拥有 N 件关联物资 + 标记已练习）
├── 成就徽章墙（v0.2）
└── 生存圈术语词典入口（v0.2）

Tab4 我的 profile
├── 准备度大雷达图（六维：五大分类拥有率 + 技能练习率）
├── 数据管理：导出清单 / 导入清单（JSON，v0.2）
├── 主题设置（v0.1 纯深色；v0.2 可选"军用浅色"）
└── 关于 & 免责声明
```

## 4. 核心功能设计

### 4.1 动态清单（核心循环）

- 物资卡三态：**未拥有 → 已拥有（勾选）→ 已过期提醒**（v0.2，食物/药品带保质期提示）
- 勾选即时反馈：做旧印章式"√"盖章动画 + 分类完成度跳动
- 每条物资含：名称、优先级（P1 生死攸关 / P2 重要 / P3 加分）、数量参考（如"净水片 × 50"）、一句话说明、场景标签
- 长按/点击展开：详情说明 + 为什么需要它 + 关联技能

### 4.2 场景化推荐

- 选场景 → 显示该场景的**推荐物资组合**（不是全量清单，是按场景裁剪的子集，按优先级分组）
- 场景准备度 = 该场景关联物资的拥有率
- 场景专属提示卡（如核污染区：远离窗边、碘片遵医嘱）

### 4.3 准备度评分（游戏化核心指标）

```
总准备度 = Σ(分类权重 × 分类拥有率) × 0.7 + 技能 practiced 率 × 0.3
分类权重：食物饮水 0.25 / 医疗急救 0.25 / 防护工具 0.2 / 能源通讯 0.2 / 文件身份 0.1
```

- 展示为 0-100 数字 + 六维雷达图（"我的"Tab 大图，首页小图）
- 评分段位（黑色幽默命名）：0-20 纯脆皮 → 21-40 普通路人 → 41-60 有备而来 → 61-80 老练幸存者 → 81-100 废土传说

### 4.4 技能树（v0.2）

- 5 分支 × 3 级（入门/进阶/精通），共 15 节点：净水、急救、庇护所、导航、通讯与求救
- 解锁条件 = 拥有关联物资（如"净水入门"需拥有净水片或滤水器）+ 用户手动标记"已练习"
- 解锁反馈：节点点亮 + 短促 Glitch 闪光 + 准备度技能分提升

### 4.5 成就徽章（v0.2）

- 示例：初出茅庐（总准备度 20）/ 有备无患（P1 物资全拥有）/ 多面手（3 技能分支入门）/ 废土传说（总准备度 80）

## 5. 交互与动效设计

| 交互点 | 设计 |
|--------|------|
| 启动加载 | **雷达扫描骨架屏**：conic-gradient 扫描线旋转 + 逐条"加载物资数据库…"终端文字，1.2s 内完成（可跳过） |
| 页面转场 | **Glitch 故障风**：clip-path 抖动 + RGB 色散双影，时长 ≤ 300ms，克制不晃眼 |
| 勾选物资 | 做旧方框 → 印章"√"砸下（scale 1.2→1 + 微旋转）→ 物资卡变灰绿"已入库" |
| 完成度变化 | 进度条液体填充感 + 数字滚动；准备度变化时雷达图弹性过渡 |
| 优先级标记 | P1 红色警示章、P2 黄、P3 灰，均做旧纹理（低透明度噪点 overlay） |
| 空状态 | "该区域辐射值过高，暂无数据…"式黑色幽默文案 |
| 弱动效模式 | 尊重 `prefers-reduced-motion`：关闭 Glitch 与扫描动画 |

**动效总原则**：氛围靠质感（纹理/配色/字体），动效只做点睛。全站动效时长 ≤ 400ms，无循环大动画（雷达屏除外，仅加载时）。

## 6. 游戏化与留存（中度）

- **每日打开理由（v0.2）**：首页终端推送一条"生存冷知识"或"检查提醒"（如"你的净水片还有 3 个月过期"）
- **收集感**：物资勾选即收集，分类进度条 + 雷达图可视化成长
- **炫耀分享（v0.2）**：准备度雷达图生成分享卡片（含段位称号），适配小红书/朋友圈尺寸
- **不做**：体力值、每日签到打卡、重氪闭环——保持工具属性，游戏化只服务"完成准备"这一目标

---

## 7. 内容合规红线（可发布产品的底线）

1. **医疗物资**：处方药类（如抗生素）只做"存在提示 + 遵医嘱备药"，不提供剂量与购买渠道
2. **官方对齐**：内容框架参考应急管理部《家庭应急物资储备建议清单》，App 内"关于"页注明定位：**家庭应急准备的科普工具，非军事/极端生存指导**
3. **不引导极端化**：不出现武器类物资；场景描述用"应急/避险"框架，避免渲染暴力与恐慌
4. **免责声明**：Tab4 内置固定声明——本 App 内容为一般性应急科普，不构成专业救援/医疗建议，灾害请以官方预警与专业机构指令为准
5. **数据隐私**：清单数据仅存本地，无账号无上传；隐私声明一句话讲清

---

## 8. 页面流程（关键路径）

```
首次启动 → 雷达加载屏（1.2s）→ 清单 Tab（全未勾选，引导文案："从 P1 开始，先活下来"）
勾选若干物资 → 准备度跳动 → 场景 Tab 选"城市避难" → 看到缺口提示（"该场景还缺 3 件 P1 物资"）
→ 按缺口采购 → 回来勾选 → 准备度上升 → 分享雷达图
```

---

## 9. 成功标准（v0.1 验收）

1. 手机优先响应式（375px 宽度下完美呈现，桌面端居中收窄）
2. 5 分类 ≥ 50 条物资数据完整（名称/优先级/数量参考/说明/场景标签）
3. 勾选、完成度、总准备度计算准确，刷新后状态保持（localStorage）
4. 3 个场景推荐组合正确（关联物资无遗漏）
5. 雷达加载屏、Glitch 转场、印章勾选三大动效齐备且尊重 reduced-motion
6. 废土风设计 Token 全站一致（对照 03 文档），无突兀的默认组件样式
7. 内容合规：处方药条目带提示，关于页含免责声明
